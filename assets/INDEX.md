# ハート泥棒 MV素材

全32点。PNG形式です。キャラクターA（紺色ツインテール）とB（コーラル色のボブ）のデザイン・配色を全素材で揃えています。

## キャラクター設定

- `character_a_design.png` / `character_b_design.png` — キャラクター設定シート
- `character_a_turnaround.png` / `character_b_turnaround.png` — 前・横・後ろの向き

## 透過キャラクター差分

Aのピース、歓声、りんご、スマホ確認、待つ表情、おまじない小物の差分と、Bのピース、歓声、りんご、ハート泥棒ポーズ、指差し、ダンス差分を収録。

## 歌詞・小物

- `prop_pinky_ring.png` — ピンキーリング
- `prop_love_charm.png` — 恋のおまじない
- `prop_bitten_apple.png` — かじったりんご
- `prop_generic_story_phone.png` — 架空のストーリー画面を表示するスマートフォン。実在SNSのロゴや画面は使っていません。

## 背景

- `bg_verse_ring_charm.png` — リング／おまじない
- `bg_prechorus_wait.png` — 「ちょっと待って」
- `bg_chorus_heartstage.png` — ハート泥棒のサビ
- `bg_social_night.png` — ストーリーと不安

## シルエット

黒シルエットは透過PNGです。白シルエット4点は生成上の都合で黒背景のPNGです。動画編集では合成モードを「スクリーン」にすると黒が抜け、白い形だけを重ねられます。

## 構図メモ

カメラ目線のポーズと、りんご・スマートフォン・画面外を見るポーズを混ぜています。スマートフォン内のBの写真は上から撮った構図です。背景も目線の高さ、ややロー、俯瞰を使い分けています。

曲の長さは約1分59秒です。仮配置案は、Verseをリング／おまじない、Pre-chorusをAの待つ差分、Chorusをハートステージ、Verse 2をスマートフォンと夜景に対応させています。

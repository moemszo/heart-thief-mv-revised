# Claude Codeへの引き継ぎ確認

## 変更

- `.gitignore` の全件除外と許可リストを廃止。秘密情報・個人設定のみを対象に変更。
- `CLAUDE.md`、実行コマンド、依存関係を固定した `package.json` / `package-lock.json` を追加。
- 現行v2の画像・MP3・字幕素材・音声解析のパスをリポジトリ基準に変更。FFmpegをPATHまたは環境変数から使うようにし、出力先を自動作成。
- Noto Sans JPとSIL OFL 1.1ライセンスを同梱。元のフォントと異なるため、再出力時のタイトル字形に差が出る場合がある。
- 元の制作コードを `production/archive/v2/` に保持。任意の画像・動画QAスクリプトも `production/archive/qa/` に追加。
- 元画像のプレビュー一覧、MP3の直接URLを追加。会話を今回の引き継ぎ依頼まで更新。

## 確認

- 採用画像32枚・生成途中26枚は追跡対象で、元のファイルとSHA-256一致。原文プロンプト62件と公開会話62項目を収録。
- MP3の公開Raw URLから HTTP 206・`audio/mpeg` の応答を取得し、実データのID3ヘッダーを読めることを確認。
- 新しい作業用ディレクトリで `npm ci` を実行し、固定した依存パッケージを取得。その依存関係と同梱フォントを使って現行v2を実行。
- サビ4秒を960×540・30fps・120フレーム、48kHzステレオ音声付きで書き出し。エンコーダー警告なし、全編デコードエラーなし。
- タイトルと字幕を含む静止画3枚を出力し、タイトルと静かな場面の表示を目視確認。
- 全118.8秒の再書き出しは今回行っていない。提出済みの全曲MP4は保持。
- 実行確認した環境はmacOS。Windows/Linuxでの実行は未確認。

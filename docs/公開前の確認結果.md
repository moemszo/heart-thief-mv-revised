# 公開前の確認結果

- 完成素材32枚と生成途中26枚の、生成画像58ファイルを収録。元ファイルとSHA-256一致。
- 22件の画像生成呼び出しから62件の実際のプロンプト本文を復元。公開用コピーのプロンプト本文62件すべてが元記録と一致。参照画像のパスのみ変更。
- 公開会話62項目（ユーザー16項目、アシスタントの回答・進捗・質問46項目）を収録。非公開の内部指示・推論は含めていない。
- APIキー、秘密鍵、個人のローカルパス、個人メール、元MP3のアカウント名・作品IDについて検査し、公開対象に未処理の該当なし。
- 画像内のC2PA証明書にある証明機関の公開連絡先は、opensslで証明書の発行主体を確認したうえで保持。ユーザーのメールアドレスではなく、画像の生成証明に付随する情報。
- ユーザー添付の参照PNGのExifは色空間と画像サイズのみ。生成画像の画素・C2PA情報は変更していない。
- MP3は再エンコードせず、識別用ID3タグと埋め込みカバーを除去。48kHzステレオのデコードPCMのSHA-256が元音源と完全一致。
- 動画は既存のファイルをそのまま収録。完成版の映像・音声検証結果は `production/v2/verification.json` に記録。
- 通常のGit対象に100MiBを超えるファイルなし。大きい字幕前MP4はReleaseに添付。

これは保存された会話・素材とパターン検査に基づく確認です。公開用に加工した範囲は `session/REDACTION_POLICY.md` を参照してください。制作ソースの追加移植・実行確認は `Claude_Code引き継ぎ確認.md` に記録しています。

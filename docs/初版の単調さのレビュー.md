# MVの画角変化レビュー

## 所見

`timeline.json` は全52ショット、全長118.8秒。切り替え数は足りている一方、画面距離と被写体の見せ方が似た型に戻るため、連続再生では単調に見えやすい。`render.cjs` では人物の横移動は冒頭0.65秒の最大120px、その後の揺れは約15px、背景の移動も横65px・縦9px程度で、静止画の位置替えが主な動きになっている。

反復が目立つ区間は、①27.82–52.54秒と81.44–110.22秒のサビ群（同じheartstage、chorus、triptych、silhouettesの型を反復）、②54.40–75.82秒の21.42秒（7ショット連続で`bg_social_night`、phone/social/anxietyのカード構図を反復）、③character_b_heartthiefのdetail/portrait（32.10–35.40秒、85.76–89.14秒で同じ並び、さらに94.50–96.52秒にdetailが再登場）。`chorus`は7回、`triptych`と`silhouettes`は各5回、`ringmacro`は4回ある。とくに32.9秒と86.4秒の既存フレームは、同じ人物・同じ横長カードの寄りが再現されている。

## 残す静かな場面

- 18.36–21.66秒の`wait`は3.30秒の間と余白が、サビ前の緊張を作る。ここには寄りや追加ズームを挟まず、現状の広い構図を保つ。
- 75.82–78.65秒の`portrait`は、不安パートからサビへ向かう小休止として残す。
- 112.08–118.80秒の`outro`は6.72秒を確保し、ロゴが落ち着いて読める締めを保つ。

## 客観的な受け入れ基準

1. 1拍程度の画角挿入を計6点以上実装し、顔寄り2点以上・腰上2点以上・手または小道具寄り2点以上を含める。目安は顔の高さが画面高の30–45%、腰上の人物が画面高の60–80%、手と対象物が画面幅の20%以上または画面高の18%以上。
2. 上記2つのサビ反復区間のそれぞれに、wide・medium・closeのうち3段階を最低1回ずつ含める。同一サイズの人物ショットを3カット連続させない。
3. 全体尺は118.8秒を維持し、`wait`は広い構図で連続3.0秒以上、`outro`は6.0秒以上を残す。

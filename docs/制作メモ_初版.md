# ハート泥棒 MV

提供音源と、このチャットで作成した人物・背景・小物・シルエットを使った2DモーショングラフィックスMVです。

- 本編：`ハート泥棒_MV_字幕前.mp4`
- 長さ：118.8秒（全曲）
- 映像：1920×1080、30fps、H.264
- 音声：AAC、48kHz、ステレオ
- カット数：52

リングとおまじないから始まり、サビで表情の寄り・3分割・色付きシルエットへ展開。2番ではスマートフォンと写真カードを組み合わせ、終盤はダンスのポーズと小物の接写を経てタイトルに戻ります。背景と人物で移動量を変えた奥行き、斜めの画面切り替え、円形の開閉、ズーム、ハートや星の動きを使用しています。

歌い出し・歌詞区間は提供音源をローカルで解析し、約129.3 BPMの拍候補と合わせてカットを配置しました。歌唱の自動認識には時刻の誤差があり得るため、字幕用の確定タイムコードとは区別しています。

字幕制作に使う指定サイトのURLがメッセージに含まれていないため、現在の本編には歌詞字幕をまだ載せていません。URL確認後、そのサイトで作成した字幕を合成する予定です。映像内の曲名はタイトルデザインです。

元の画像素材は変更していません。白シルエットの黒背景は、映像合成内で抜いています。

## 書き出し後の確認

- ffprobe：映像・音声ともに118.800秒。1920×1080、30fps、映像3,564フレーム。
- 全編をFFmpegでデコード：エラーなし。
- 書き出した映像から12場面を抽出して確認。顔の寄り、シルエット、スマホの俯瞰、写真カード、終端タイトルを確認。
- 元音源と出力音声を12kHzのモノラルPCMにして比較した同時刻の相関係数：0.999889。出力AACには約5.3msのデコード末尾パディングがあるが、コンテナ上の音声長は118.800秒。
- QuickTimeで開く操作は実施。画面ロックによりUI確認が阻まれたため、プレーヤー上の実再生・試聴は未確認。
- 残作業：指定サイトのURL受領後、そのサイトで歌詞字幕を制作して合成する。

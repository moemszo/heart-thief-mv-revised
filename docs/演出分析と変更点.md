## 現行版から変更した点

- 60カット。人物が映らない区間は52.08秒（約44%）。シルエットや人物入りスマホは「人物なし」に数えていません。
- 顔・上半身・手元・目元の寄りは61.54秒。全身を主役にした舞台カットは3.98秒。冒頭タイトルの人物は別区分です。
- 全画面で常に揺れる動きを減らし、短い切り替えと長めの静かな場面を組み合わせる。
- サビの入口は人物を外し、ハートと大きな歌詞を主役にする。
- 2番の「いいね」は人物を含まないオリジナルの通知画面。不安な場面で通知から顔へ切り替える。
- 人物の元画像は同じものを使い、顔立ち・衣装・色を維持。カメラの寄りと切り取りで画角を変える。

## 歌詞字幕

指定された [JIZURA](https://852wa.github.io/JIZURA/) のウェブ画面で制作・MP4書き出しを行いました。提供歌詞20行を維持し、ローカル音源の自動認識から得た行開始時刻をLRC形式で入力。間奏2区間も明示しました。場面ごとに登場方法・保持する動き・退場方法を選び、書き出した字幕をMVの余白へ配置しています。

| 場面 | 字幕の演出 |
|---|---|
| 恋のおまじない・不安 | 小さめの字、ぼかしからの出現、穏やかな消え方。顔を避けて余白に配置。 |
| ちょっと待って・わたしの番 | 強めの出現と一文字ずつの表示で、呼びかけを強調。 |
| ハート泥棒あなた | 人物なしのハート画面で大きく登場。人物に切り替わると字幕を横の余白へ移す。 |
| ストーリー | 通知風の字幕と、人物・実在ロゴを含まないスマートフォン画面。 |
| 罪な人 | 太い短文を大きく置き、りんごや目元と組み合わせる。 |

字幕の編集用JSONとLRC、JIZURAからの黒背景の字幕素材も保存しました。元の映像は残し、今回の版は別ファイルとして出力しています。

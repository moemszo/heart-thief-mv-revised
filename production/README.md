# 制作ソース

`v2/` のレンダラーは、このリポジトリの素材・MP3・字幕動画を参照するように整えています。リポジトリ直下で `npm ci` と `npm run render:preview` を実行できます。Node.js 20以降とFFmpegが必要です。

詳しい手順・編集箇所は [CLAUDE.md](../CLAUDE.md) を参照してください。

| フォルダ | 用途 |
|---|---|
| `v2/` | 現行版。移植したレンダラー、字幕JSON調整スクリプト、60カットのタイムライン。 |
| `archive/v2/` | 移植前の制作ソースを保存した記録。個人パスをプレースホルダーに置換済み。 |
| `v1/` | 字幕前の初版の制作記録。元環境のパスはプレースホルダー。 |
| `audio_analysis/` | 元音源の解析・歌詞認識の記録。 |

元工程の検証結果は各フォルダ内に残しています。現在の引き継ぎ確認は `docs/Claude_Code引き継ぎ確認.md` に記録しています。

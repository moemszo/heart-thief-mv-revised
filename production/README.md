# 制作ソースの記録

`v1/` は字幕前の初版、`v2/` は演出改訂版の制作時のコードとタイムラインです。
個人パスは `[LOCAL_WORKSPACE]`、`[LOCAL_HOME]`、`[FFMPEG]` 等に置き換え、素材参照は収録先に変更しています。
これらは原工程を理解するためのソース記録で、クローン後にそのまま実行できる配布アプリではありません。実行にはNode.js、`@napi-rs/canvas`、FFmpeg、Pythonと各コードが使用するライブラリ、および日本語フォントが必要です。
元工程の検証結果を同梱しています。公開用パスへ変更したコードの再実行はしていません。

# ハート泥棒 音声解析メモ

## 入力と長さの照合

- 入力: `media/audio/ハート泥棒.mp3`
- `ffprobe`: MP3、48,000 Hz、stereo、118.800000 秒。`lyrics-eng` は通常テキストで、時刻情報は含まない。
- `ffmpeg` で48 kHz stereo float PCMへデコードした結果は各ch 5,702,400 sample、118.800000 秒。ffprobeとの差は0秒。

## 音響特徴とテンポ

- `analysis.json` に0.1秒刻み1,188点の全曲RMS、150 Hz以下のRMS、onset強度の平均/ピークを格納。
- Onsetは2048点Hann窓、10 ms hopのスペクトルフラックス。全曲99.5 percentileで相対正規化。
- 粗い自己相関候補は64.516 BPM (周期0.93秒、位相0.49秒)、85.714 BPM (0.70秒)、130.435 BPM (0.46秒)。64.516の2倍に近い格子は別途細密比較した。拍の取り方は粗い自己相関だけでは確定できない。
- 126–132 BPMを0.01 BPM刻みで、10 ms onset列に対するgridの位相を3 ms刻みで最適化。2.01秒移動平均を引いたonsetを比較し、最良候補は **129.30 BPM / 位相0.108秒**。129.03 BPMは位相0.024秒・score 0.72821 (rank 70)、130.43 BPMは位相0.219秒・score 0.17395 (rank 259)。この範囲では129.30のgrid一致度が高い。
- 129.78 BPMの次点ピークもscore 1.02421と近く、129.30の次点差は約5.3%。したがって129 BPM前後は支持されるが、小数点以下の正確なテンポは確定しない。grid scoreは相対一致度で、確率や拍子の確定値ではない。粗い候補と細密scanそれぞれのbeat時刻列をJSONに保存。

## 歌詞と区間候補

- 全曲ASRはローカルキャッシュの `Systran/faster-whisper-medium` をCPU int8で実行。`HF_HUB_OFFLINE=1`、promptなし。新規モデル取得・外部アップロードなし。
- 12個のASR segmentとword timestampを保存。埋め込み歌詞と隣接ASR word列が正規化後に完全一致した13行だけ、行タイム候補として記録。誤認識/未一致行には推測時刻を割り当てていない。歌唱ASRなので生テキストも併記。
- 歌詞見出し順とsegment内容からの区間開始候補: Verse 2.24秒、Pre-chorus 18.36秒、Chorus 27.82秒、Verse 2 57.26秒、Pre-chorus 72.56秒、Chorus反復 81.44秒。セクション時刻はWhisper segment境界で、音素単位の正確な開始時刻ではない。
- ASRで歌詞が検出されない区間: 0–2.24秒、26.16–27.82秒、42.72–57.26秒、96.52–118.8秒。特に最後の区間は96.5–116.5秒のRMS中央値が-18.42 dBFSで音楽が続くため、長いインストゥルメンタルアウトロ候補。末尾は約117.8秒から-60 dBFS未満へ減衰。
- 別枠の音響変化点候補は、前後4秒のRMS/low-frequency/onset変化によるもの。17.2、57.8、70.6、79.9、114.6秒など。歌詞見出しと自動対応させていない。

## 無音判定

100 ms RMSを-60 dBFS閾値とした場合、冒頭の閾値未満区間は約0.1秒、末尾は約1.0秒。PCMが完全なゼロのサンプル連続区間は両端とも0秒（MP3デコードノイズを含む）。

`analysis.json` は値の定義、手法、信頼度の限界、全時刻配列も含む。
